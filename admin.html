The Studio verifies your GitHub identity before allowing repository access. Your token stays in this browser tab only.

How do I create the right token?
  1. Open GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Select only this portfolio repository.
  3. Grant Contents: Read and write, then generate the token.
  4. Paste it above. It is held only for this tab.
